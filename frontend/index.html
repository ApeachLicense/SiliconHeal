Section 4.2 DMA Alignment & Control Register Page 14

4.2.1 64-Byte Cache-Line Address Alignment [CRITICAL]

Both DMA_SRC_ADDR and DMA_DST_ADDR MUST be aligned to a 64-byte boundary (addr & 0x3F == 0). Unaligned pointers immediately raise ERR_DMA_UNALIGNED_64B.

4.2.2 DMA_CR Bit 7 (RSVD_MBZ) & Bit 4 (BURST_16)

  • Bit 7 (0x80 RSVD_MBZ): Factory Debug Bus Lock. Writing 1 locks the AXI4 arbiter and triggers ERR_AXI_BUS_DEADLOCK.
  • Bit 4 (0x10 BURST_16): Enables 16-beat AXI4 burst mode, cutting DMA bus overhead by 14x (DMA_CR = 0x15).
Section 5.1 Cache Coherency & MMIO Polling Page 27

5.1.1 Mandatory Data Memory Barrier (hw_dmb)

The DMA engine reads physical DRAM directly, bypassing L1 Data Cache. Software MUST invoke hw_dmb() prior to triggering DMA. Omitting hw_dmb() causes DMA to fetch stale cache lines (87.5% silent CRC32 corruption).

5.1.2 Volatile DMA_SR Status Register Polling

Polling DMA_SR without volatile qualification (hw_poll_status_volatile()) causes compiler register caching at -O2, reading partial tiles before transfer completion.

Section 6.4 8-Bank Interleaved SRAM Architecture Page 41

6.4.2 The 32-Byte Column Stride Bank Conflict Trap

Local SRAM has 8 parallel 32-bit banks (Bank = (word_idx) mod 8). In an unpadded float local_tile[8][8], row stride is 8 floats (32B). Column gather across rows r = 0..7 accesses (8r + c) mod 8 = c — all 8 vector lanes collide on the exact same bank (94.1% conflict, 16x pipeline stall)!

6.4.3 Fix: +1 Float Row Padding (gcd(9, 8) = 1)

Declare float local_tile[8][8 + 1] (stride = 9 floats = 36B). Column accesses map to (9r + c) mod 8, distributing across all 8 banks with 0.0% Bank Conflict and achieving a 18.9x latency speedup.
